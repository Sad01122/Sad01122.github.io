What Is a Proposition?

💡
Definition 1. A proposition is a declarative sentence that is either true or false, but not both. Variables p, q, r… stand for propositions · truth values T / F. Aristotle systematized logic >2300 yrs ago · Boole, 1854 studied compound propositions (Not, Or, And).

p → q — All the Ways to Say It

🗣️
Hypothesis (p) side: "if p" · "p implies q" · "p is sufficient for q" · "q follows from p" · "q whenever p".
Conclusion (q) side: "q if p" · "p only if q" · "q is necessary for p" · "a necessary condition for p is q" · "p is a sufficient condition for q" · "q unless ¬p" · "if p, q" · "q when p".
⚠️
only if introduces the then-part → "You can pass only if you attend" = If you pass, then you attended. · sufficient → left (p) · necessary → right (q).

Converse · Contrapositive · Inverse

FormStatementEquivalent to p → q?
Converseq → p✗ no
Contrapositive¬q → ¬p✅ always — same truth values
Inverse¬p → ¬q✗ no (but ≡ converse)
✅
Only the contrapositive keeps the truth. Converse & inverse are equivalent to each other, not to the original.

🎯 Section 2 — Quick Drills

Q1

When is p → q false?

↻ tap
A

Only T → F — a promise breaks only when kept-then-betrayed. False hypothesis = automatically true.

Q2

Which form of p → q is equivalent?

↻ tap
A

The contrapositive ¬q → ¬p. Converse (q→p) and inverse (¬p→¬q) are NOT.

Q3

"p only if q" → which form?

↻ tap
A

p → q — "only if" gives the conclusion (q is necessary for p).

Q4

Operator precedence order?

↻ tap
A

¬ > ∧ > ∨ > → > ↔ — negation first, biconditional last.

Logic Meets Bits

  • Truth ↔ bits: T = 1, F = 0 — the same truth tables wearing 0/1 costumes
  • Definition 7. A bit string is a sequence of zero or more bits; its length = number of bits — 101010011 has length nine
  • Bitwise rules: OR → 1 if any 1 · AND → 1 if both 1 · XOR → 1 if different
PositionA = 0110 1011 0110B = 1100 0001 1101
OR1110 1011 1111
AND0100 0001 0100
XOR1010 1010 1011
🧮
Do it bit by bit, same position with same position: 0∨1=1 · 0∧1=0 · 0⊕1=1. Group bits in 4s (nibbles) for readability.

🧠 Memory Tricks — Whole Topic

  • Proposition test: must be declarative + definitely T or F — questions, commands and variable-riddled sentences fail. "Declares a fact? Settled true or false?"
  • Connectives word: Not · And · Or · If-then · Iff → NAOI-I.
  • → fails only at T→F — generous to false hypotheses.
  • Contraposite flips and negates = keeps the truth · converse just flips · inverse just negates. "Only the contra keeps the truth."
  • ↔ = twins → true when p and q match (TT or FF).
  • Sufficient → left (p), necessary → right (q).
  • Range of →: T,T→T · T,F→F · F,*→T.
  • Precedence ladder: ¬ ∧ ∨ → ↔ ("Not first, Iff last").
