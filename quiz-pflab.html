⭐ Week 1 — C++ Foundations

Q1

Two lines every C++ program needs?

↻ tap
A

#include <iostream> (input/output) + int main() — execution begins here; return 0; = normal end.

Q2

cin >> vs cout <<?

↻ tap
A

cin >> reads keyboard input into a variable · cout << sends text/values to the screen. endl = new line + flush.

Q3

Program vs language? Syntax vs logic error?

↻ tap
A

Program = instructions doing a task · language = notation (C++). Syntax = breaks grammar → won't compile · logic = compiles but wrong answer.

Q4

Pick the type: age, GPA, grade, active?, name, PI?

↻ tap
A

age → int · GPA → double · grade → char · active → bool · name → string · PI → const double PI = 3.14159; (never changes).

Q5

Why does 7 / 2 give 3, not 3.5?

↻ tap
A

Integer division — both operands int → fraction discarded. Fix: make one operand double (7.0 / 2 or static_cast<double>(7) / 2) → 3.5.

Q6

Six-step programming workflow?

↻ tap
A

Understand → Plan (Input→Process→Output) → Code → Compile → Run & Test → Debug. Debug rule: change one thing at a time.

⭐ Week 2 — Operators, Casting, Formatted Output

Q1

17 % 5 = ? What does % do?

↻ tap
A

2 — modulus = remainder (17 ÷ 5 → quotient 3, remainder 2). Works on integers only; great for parity: n % 2 == 0 → even.

Q2

Trace: x=20; x+=5; x-=3; x*=2; x/=4; x%=4;

↻ tap
A

20 → 25 → 22 → 44 → 11 → 3. Compound ops update the existing value — trace after every statement.

Q3

Implicit vs explicit conversion? What does static_cast<double>(7) / 2 give?

↻ tap
A

Implicit = compiler converts automatically (int→double). Explicit = you force it with static_cast<>. Result = 3.5 (now decimal division).

Q4

Formatted output: setw, fixed, setprecision, boolalpha?

↻ tap
A

setw(10) = min width for the next item · left/right = alignment · fixed + setprecision(2) = exactly 2 decimals (87.45678 → 87.46) · boolalpha prints true/false not 1/0. Header: <iomanip>.

Q5

'5' - '0' = ? digit - '0' trick?

↻ tap
A

5 (int) — char arithmetic uses ASCII: '5' is 53, '0' is 48 → 53−48 = 5. The standard character-to-integer conversion.

Q6

setprecision(4) without fixed — decimal places or digits?

↻ tap
A

Without fixed it caps significant digits (123456 → 1.235e+05). Pair it with fixed to mean decimal places.

⭐ Week 3 — Characters, Strings & Decisions

Q1

cin >> name vs getline(cin, fullName)?

↻ tap
A

cin >> reads one word (stops at space) · getline reads the whole line. After cin >> x the leftover newline breaks getline → use cin.ignore() first.

Q2

<cctype> quartet?

↻ tap
A

isalpha letter · isdigit digit · isalnum letter OR digit · isspace whitespace · plus toupper / tolower.

Q3

= vs == — the #1 mistake?

↻ tap
A

age = 18 assigns (stores 18) · age == 18 compares (true/false). if (pass = correct) stores and is always "true-ish" → classic bug.

Q4

&&, ||, ! in one line?

↻ tap
A

&& both must be true · || at least one true · ! reverses. Short-circuit: && stops at first false, || at first true.

Q5

else-if ladder trace: marks = 74? Switch without break?

↻ tap
A

74 ≥ 80 false → 74 ≥ 70 true → prints "B", rest skipped (first true wins). Missing break in switch = fall-through into the next case.

Q6

What is a flag? Valid range 0–100?

↻ tap
A

Flag = bool remembering whether something happened (bool validInput = true; → set false on bad input). Range: marks >= 0 && marks <= 100 (never chained 0<=m<=100).

⭐ Week 5 — Loops, Counters, Sentinels, Validation

Q1

Loop-choice rule (viva favorite)?

↻ tap
A

Fixed count → for (10 inputs) · unknown count, stop-value → while + sentinel (0 = stop) · must run at least once → do-while (PIN validation).

Q2

Sentinel loop — where does 0 go?

↻ tap
A

Nowhere — 0 is the stop signal, NOT data. Check if (severity == 0) break; before count++ / total += … or your totals are poisoned.

Q3

Task 4 bug: attempts counter declared outside the user loop?

↻ tap
A

User 2 starts with attempts already used — no tries left. Fix: int attempts = 0; must live inside the outer loop (its life begins per user).

Q4

Exactly 10 iterations — which for?

↻ tap
A

for (int i = 1; i <= 10; i++) ✅ · i = 0; i <= 10 = 11 runs ❌ · i < 10 from 1 = 9 runs ❌. Count on paper: 1…10.

Q5

Why do-while for PIN 1000–9999?

↻ tap
A

Question must be asked at least once → do { read } while (pin < 1000 || pin > 9999); — repeats only while invalid. A plain while might never run.

Q6

Why while (attempts < 3) + break for logins?

↻ tap
A

Count-controlled limit (max 3 tries) with an early exit: correct password → break (skip remaining tries). One cin inside the loop — never three copies.

🌍 Did You Know — online facts about the tools you use

🧠
C++ was created by Bjarne Stroustrup at Bell Labs in 1979 — first called "C with Classes", renamed C++ in 1983 (the ++ operator means "increment", so C++ = "C incremented"). cout = character output, cin = character input. C (1972, Dennis Ritchie) → C++ (1979) → Java (1995, James Gosling) → Python (1991, Guido van Rossum) — the family tree of what you're learning. Standard C++ versions (releases) run on every major compiler: g++ (GCC, free), Clang, MSVC.

📝 Test Quiz — 15 MCQs (lab weeks 1, 2, 3 & 5)

⚠️
Pick one option per question, then hit Check Answers. Explanations unlock after grading. Target: 12/15 (80%)+. Use Reset to retry — aim to beat your score without notes.

1In C++, execution of a program always begins at…Week 1

Answer: B. The operating system calls main() — that's where execution starts. #include runs earlier (preprocessor), but the program begins in main.

2A program compiles fine but prints the wrong result. This is a…Week 1

Answer: C. Syntax = breaks grammar → won't compile. Runtime = crashes while running (e.g., divide by zero). Logic = runs and finishes, but the answer is wrong — found by tracing/testing.

3cout << "Age: " << age; — what does it do?Week 1

Answer: A. << chains output pieces together (insertion). cin >> is the opposite — it extracts keyboard input into variables.

4Which data type fits const double PI = 3.14159; best — and why const?Week 1

Answer: D. PI needs decimal precision (double), and const locks it — any later attempt to change it fails to compile. int would truncate to 3.

5int a = 17, b = 5; — the expression a % b evaluates to…Week 2

Answer: B. % = remainder of integer division: 17 = 5 × 3 + 2. (Quotient 3 is what a / b would give.) Modulus works on integers only.

6int x = 20; x += 5; x -= 3; x *= 2; x /= 4; x %= 4; — final x?Week 2

Answer: C. Trace it: 20→25→22→44→11→ 3 (11 % 4 = 3). Each compound operator reads, computes, and stores back into the same variable.

7To get 3.5 from integers 7 and 2 you must…Week 2

Answer: A. int ÷ int = integer division (7/2 → 3, fraction dropped). Cast one operand to double → decimal division → 3.5. fixed/setprecision only change printing, not math.

8cout << fixed << setprecision(2) << 87.45678; prints…Week 2

Answer: B. fixed + setprecision(2) = exactly two digits after the decimal point, rounded: 87.45678 → 87.46. Without fixed, setprecision would count significant digits instead. Needs <iomanip>.

9After cin >> age; you call getline(cin, name); and name comes back empty. Fix?Week 3

Answer: C. cin >> leaves the Enter-key newline in the buffer; getline then reads that empty line. cin.ignore() throws it away so getline reads the real input.

10marks = 74 with the ladder: ≥80 → "A", ≥70 → "B", ≥60 → "C", else…Week 3

Answer: B. The ladder tests top-down and stops at the first true branch: 74 ≥ 80 false → 74 ≥ 70 true → prints "B". This is why the strictest band (90/80) must come first.

11Which expression accepts marks only from 0 to 100?Week 3

Answer: D. Range ends join with &&. Option A isn't valid C++ chaining (C++ has no Python-style chained comparison), B is almost always true, C allows 101–1000.

12In the sentinel loop, input 0 should…Week 5

Answer: B. The sentinel ends the loop and is never counted/added — check it first, then break. Counting it poisons both count and totalSeverity.

13Which loop reads exactly 10 event codes?Week 5

Answer: C. 1…10 inclusive = exactly 10 runs. A runs 11 times (0–10), B runs 9 times (1–9), D is an infinite loop (condition always non-zero).

14In Task 4 (nested logins), placing int attempts = 0; outside the user loop causes…Week 5

Answer: A. The counter never resets, so user 1's 3 tries carry over — users 2 and 3 are locked out instantly. Declare counters inside the outer loop, where their life begins.

15Why is do-while the right loop for PIN validation (1000–9999)?Week 5

Answer: D. do-while always executes its body once, then re-checks: while (pin < 1000 || pin > 9999). A plain while could skip the first question entirely.
