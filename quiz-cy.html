⭐ Foundations & CIA (Lecture 1)

Q1

Define cybersecurity in one line.

↻ tap
A

The ongoing effort to protect systems, networks, programs & data from unauthorized access, misuse, damage or disruption.

Q2

The CIA triad — meanings + one threat each?

↻ tap
A

Confidentiality (only authorized see — threat: leakage) · Integrity (accurate, unmodified — threat: tampering) · Availability (reachable when needed — threat: outage/DoS).

Q3

Four verbs + four cyberspace properties?

↻ tap
A

Verbs: Protect → Detect → Respond → Recover · Cyberspace: virtual, borderless, interactive, persistent.

Q4

Ransomware — which CIA letters?

↻ tap
A

Mainly A (service unusable) — usually C + I too (data encrypted/exfiltrated).

Q5

What made cybersecurity harder? Name 4 incidents.

↻ tap
A

Connectivity. Stuxnet 2010 · Ukraine grid 2015 · Mirai 2016 · WannaCry 2017.

Q6

Data records types? Why data > device?

↻ tap
A

MED, EDU, JOB, FIN, DEV · attackers want credentials & identity — the data inside matters more than the hardware.

⭐ Principles & AAA (Lecture 2)

Q1

List the six security principles.

↻ tap
A

Least privilege · Defense in depth · Secure defaults · Separation of duties · Fail securely · Minimize attack surface.

Q2

AAA — questions, order, one failure each?

↻ tap
A

Authenticate (who?) — stolen password accepted · Authorize (what?) — student edits another's record (IDOR) · Account (log?) — admin action with no record. Order: N before Z.

Q3

Password + user PIN — multi-factor?

↻ tap
A

No — both are knowledge factors. Real pair: password + authenticator app (knowledge + possession).

Q4

Authorization models — one line each?

↻ tap
A

DAC owner decides · MAC central labels · RBAC job roles (university) · ABAC attributes · rule-based system conditions.

Q5

5 questions of a useful event?

↻ tap
A

Who · What · Where · When · Outcome — capture → protect → review.

⭐ Risk, Actors & Frameworks

Q1

Asset / Threat / Vulnerability / Attack / Risk?

↻ tap
A

Asset = what's valuable · Threat = potential harm · Vulnerability = exploitable weakness · Attack = intentional attempt · Risk = Likelihood × Impact.

Q2

The risk chain (order)?

↻ tap
A

Asset → Vector → Threat/Vulnerability → Attack → Impact (A-V-T-A-I).

Q3

5 threat actors? Vector vs technique?

↻ tap
A

Cybercriminal · Insider · Hacktivist · Nation-state · Opportunist. Vector = route in (phishing email) · technique = how they operate.

Q4

ATT&CK: tactics vs techniques + chain?

↻ tap
A

Tactics = why (goal) · techniques = how (method). Chain: Initial Access → Execution → Credential Access → Collection → Impact.

📝 Test Quiz — 15 MCQs

⚠️
Pick one option per question, then hit Check Answers. Explanations unlock after grading. Target: 12/15 (80%)+. Reset to retry without notes.

1A backup folder is left world-readable and strangers download student records — which CIA property is breached?CIA

Answer: B. Unauthorized eyes saw private data = disclosure/leakage → Confidentiality. (Nobody changed the data → not I; nothing stopped access → not A.)

2Ransomware encrypts the whole LMS — it mainly threatens which CIA property?CIA

Answer: C. The service becomes unusable for real users — A first. (Exams often add: C and I are usually hit too.)

3The correct order of the four cybersecurity verbs is…Basics

Answer: C. Memory trick: "Please Don't Ruin Recovery" — you protect first, recover last.

4Which is NOT a property of cyberspace?Basics

Answer: D. The four are virtual · borderless · interactive · persistent. "Profitable" sounds plausible but was never in the lecture.

5What made cybersecurity much harder in recent years?History

Answer: A. Connectivity = more paths, dependencies and possible attackers. The incidents (Stuxnet, Ukraine, Mirai, WannaCry) all ride on connections.

6A phishing email is which kind of attack vector?Vectors

Answer: B. The route runs through a person (impersonation/deception). Application = web/API flaw · network = exposed service/rogue Wi-Fi · supply chain = compromised vendor/update.

7Every intern is given admin rights on all systems — which principle is violated?Principles

Answer: B. Admin rights are far beyond what an internship requires — grant only the smallest permission set.

8One employee both creates and approves refunds — which principle is missing?Principles

Answer: C. Sensitive duties must be split: one initiates · another approves · a third audits.

9A password plus a user-created PIN counts as multi-factor authentication?AAA

Answer: B. MFA needs different factor types (know/have/are…). Password + PIN = knowledge + knowledge — one stolen secret defeats both. Better: password + authenticator app.

10Permissions assigned by job role (student / teacher / admin) describe which model?AAA

Answer: C. RBAC = permissions follow roles — the university example (DAC = owner decides, MAC = central labels, ABAC = attributes).

11A student changes /record/104 to /record/105 and reads a classmate's profile. Which AAA part failed?AAA

Answer: B. Login was fine (authentication worked) — the system never checked ownership of the object (broken authorization / IDOR).

12Risk is calculated as…Risk

Answer: B. Risk = Likelihood × Impact — and a control is justified by the risk it changes.

13In MITRE ATT&CK, tactics describe…Frameworks

Answer: B. Tactics = why (goal, e.g. Initial Access) · techniques = how (method). Chain: Initial Access → Execution → Credential Access → Collection → Impact.

14Which is NOT one of the five questions a useful accounting event must answer?AAA

Answer: D. The five are Who · What · Where · When · Outcome. "How much money" may be part of "what", but it is not one of the five.

15Which is NOT one of the six security principles?Principles

Answer: C. The six: least privilege · defense in depth · secure defaults · separation of duties · fail securely · minimize attack surface. "Performance by design" was never one.
