Definitions — The Opening Words

💡
Cyberspace: global interconnected digital environment — virtual · borderless · interactive · persistent. Users: individuals, organizations, governments (same space, different assets, different consequences).
Cybersecurity: the ongoing effort to protect systems, networks, programs and data from unauthorized access, misuse, damage or disruption.
Cyberattack: intentional attempt to steal / expose / alter / disable / destroy / gain unauthorized access — attacker → action → impact.
Four verbs (the whole job)Meaning
Protectprevent harm
Detectnotice trouble
Respondlimit impact
Recoverrestore service

✅
One attack, all three letters: the Ali portal incident — attacker reads data (C), changes profile (I), floods portal so it's down (A).

Data Is the Real Target

  • Personal data > name: identity (name, DOB, ID) · contact (email, phone) · behavior (searches, location, clicks) · content (photos, messages).
  • Records: MED · EDU · JOB · FIN · DEV — where your data lives.
  • Your digital day leaks: 07:30 unlock → 09:00 campus Wi-Fi → 11:00 LMS → 15:00 maps → 21:00 streaming.
  • Data > device: if the laptop is lost, the credentials & identity inside matter more than the plastic.
  • Layered effort: People (awareness) + Process (policies) + Technology (controls) — no single tool "solves" security.

🗂 The Whole Course in 8 Categories

Every term in the quiz belongs to exactly one box below. Learn the box, remember the one-line trick, and you can define anything in under 10 seconds.

3 terms
🛡 CIA Properties
  • Confidentiality — only the right eyes see it. leak = C
  • Integrity — data stays exactly as authorized; no edits, no fakes. changed = I
  • Availability — service works when needed. down = A
CIA triangle — Wikimedia Commons
Controls: C → encryption + access control · I → permissions, hashes, audit · A → backups + redundancy
6 rules
🔷 Security Principles
  • Least privilege — keys to only your room. smallest set
  • Defense in depth — onion layers, not one wall. layers
  • Secure defaults — a new thing starts locked. default = deny
  • Separation of duties — nobody holds both keys (one acts, one approves). no solo
  • Fail securely — when it breaks, it stays locked (no bypass). error ≠ open
  • Minimize attack surface — fewer doors = fewer break-ins. unused = gone
Defense in depth = layers — Wikimedia Commons
Memory: Least, Depth, Defaults, Separate, Fail (+ Minimize surface) → "L-DD-SF"
3 + models
🔑 AAA — Authn · Authz · Account
  • Authentication — who are you? Show ID. Factors: Know · Have · Are (+Context, Recovery). 2 kinds = MFA
  • Authorization — what may you do? Your menu of rights. IDOR = broken authz
  • Accounting — what did you do? The log/CCTV: Who · What · Where · When · Outcome. 5 Ws
  • Models: DAC = owner decides · MAC = label decides · RBAC = job decides (university!) · ABAC = context decides.
Order: N before Z — Authenticate → Authorize → Account. Traps: password + PIN ≠ MFA (both "Know")
5 terms
⚠️ Risk Language
  • Asset — what you'd lose (data, system, reputation, people).
  • Threat — who/what could cause harm (burglar). potential
  • Vulnerability — the open window (weakness in YOUR system). ours
  • Attack — harm actually attempted: Method → Target → Outcome. event
  • Risk — how likely × how bad. R = L × I
Chain: Asset → Vector → Threat/Vulnerability → Attack → Impact = "A-V-T-A-I"
5 actors
🎭 Threat Actors (WHO)
  • Cybercriminal — wants money. ransom/fraud
  • Insider — already inside: angry, careless or bribed. trusted access
  • Hacktivist — wants attention to a cause. ideology
  • Nation-state — wants strategic advantage. resources = huge
  • Opportunist — wants anything easy. no plan
Compare on: intent · capability · access · resources · constraints — motivation alone never defines the threat
5 vectors
🚪 Attack Vectors (WHICH DOOR)
  • Human — the click: phishing, impersonation. #1 in practice
  • Application — the flaw: web/API bug. code hole
  • Network — the pipe: open port, rogue Wi-Fi. traffic
  • Endpoint — the device: malicious file / USB. laptop/phone
  • Supply chain — the vendor/update you trust. trusted path
Phishing = the human vector — Wikimedia Commons
Vector = route in · technique = how they operate — one vector, many techniques
3 ideas
🕸 MITRE ATT&CK
  • Tactic — the WHY: attacker's goal (Initial Access, Impact...). stage name
  • Technique — the HOW: the method used inside that stage. the move
  • Shared language — describe · compare · defend the same way everyone else does.

The Comparison Cards

🦹 Threat

Potential cause of harm. The burglar roaming your street — may never choose you.

VS

📊 Risk

Likelihood × Impact. Chance he picks your house × what he'd take.

🧃 Easy: threats exist everywhere; risk = threat × your open window × value inside.
🎯 Exam line: "Threat = what could hurt us. Risk = Likelihood × Impact; controls lower the risk."

🕳 Vulnerability

Weakness in YOUR system. The unlocked window — sits there even with zero burglars.

VS

🦹 Threat

External actor/event that could cause harm — someone who might come.

🧃 Easy: a hole in the wall doesn't need a burglar to be a hole. Hole = ours, burglar = theirs.
🎯 Exam line: "Vulnerability is ours (condition); threat is theirs (potential). Risk = when they meet."

🕳 Vulnerability

A quiet condition. Window open at night — nobody has used it (yet).

VS

⚔ Attack

An actual event. Someone climbed in: Method → Target → Outcome.

🧃 Easy: vulnerability waits; attack happens. One vulnerability can face many attacks.
🎯 Exam line: "A vulnerability may never be exploited — but every attack used a vulnerability."

🪪 Authentication

Who are you? The bouncer checks your face/ID. Claim → Evidence → Decision.

VS

🎟 Authorization

What may you do? Your wristband decides which rooms you enter.

🧃 Easy: first the gate knows who you are, then your ticket decides where you go.
🎯 Exam line: "Authn proves identity; Authz grants permissions. IDOR = authn fine, authz broken."

🚪 Vector

Which door. The route to you: phishing email, open port, malicious USB.

VS

🧰 Technique

How they operate. Fake login page, keylogger, pass-the-hash.

🧃 Easy: vector = which street/window · technique = pick lock vs break glass.
🎯 Exam line: "Vector = path to the target; technique = method of action. Tactic = the goal (WHY)."

🎭 Threat Actor

WHO. The person/group: cybercriminal, insider, hacktivist, nation-state, opportunist.

VS

🚪 Attack Vector

WHICH DOOR. The route used: human, application, network, endpoint, supply chain.

🧃 Easy: same burglar can use the front door or the window — actor stays, vector changes.
🎯 Exam line: "Actors describe the attacker; vectors describe the route. Compare actors by intent/capability/resources."

📏 Principle

The rule / the WHY. "Minimize access" — a reusable decision guide.

VS

🔧 Control

The tool that enforces it. Permission groups, MFA, firewall rules, backups.

🧃 Easy: the law says "drive safely" (principle); the speed camera (control) makes you.
🎯 Exam line: "Principles guide decisions; controls implement them. Principles are the 6 rules, controls are named tools."

Risk Language & The Risk Chain

TermDefinitionWhere it lives

ThreatPotential cause of harmIntentional (phishing) · accidental (misconfig) · environmental (fire)

🧠
Risk chain: Asset → Vector → Threat/Vulnerability → Attack → Impact (A-V-T-A-I). Exam-system example: asset = exam system · vector = phishing a TA · weakness = no MFA + reused password · impact = exam disclosure, lost trust.

Actors, Vectors & MITRE ATT&CK

  • Actors: Cybercriminal (money) · Insider (access/grievance/error) · Hacktivist (ideology) · Nation-state (strategy) · Opportunist (easy targets). Compare intent vs capability vs access vs resources vs constraints — motivation alone doesn't define the threat.
  • Vectors (the route in): Human (phishing, impersonation) · Application (web/API flaw) · Network (exposed service, rogue Wi-Fi) · Endpoint (malicious file/USB) · Supply chain (compromised vendor/update). Vector = route · technique = how they operate.
  • ATT&CK: shared language to describe · compare · defend. Tactics = why (goal) · techniques = how (method). Chain: Initial Access → Execution → Credential Access → Collection → Impact.
  • Lab incident mapped: fake update link (initial access) → shared password (credential access) → unknown file (execution) → project files gathered (collection) → logs deleted & leak (impact).

🧠 Memory Tricks — Both Lectures

  • CIA triad → ask "Can I Access?" — Confidentiality, Integrity, Availability. C = someone could read it · I = someone changed it · A = absolute silence, nobody can reach it.
  • Four verbs → "Please Don't Ruin Recovery" — Protect, Detect, Respond, Recover. Defenders never stop at prevent — the cycle must end in recovery.
  • AAA order → N before Z: Authenticate → Authorize → Account. "Am I Allowed?"
  • 5+1 principles → "Least, Depth, Defaults, Separate, Fail" (+ Minimize surface). "LL-DS-F."
  • Risk chain → A-V-T-A-I: Asset → Vector → Threat/Vulnerability → Attack → Impact. "The A-V train hits the T-A-I city."
  • Tactics vs techniques → tactics = Why (W, goal) · techniques = How (H, method). ATT&CK chain: Initial access → Execution → Credential → Collection → Impact ("IE CCI").
  • PK bodies → "Pakistan Networks Need Rescue" — PECA, NTISB, NR3C · hotline 9911.
  • Ali's attack chain → Bait → Click → Credential → Access → Impact — defender breaks it anywhere.
