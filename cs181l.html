Lab Goal — One Professional Page

Create a one-page document titled "Applications of ICT in Everyday Life" demonstrating every Week-01 Word feature. Save immediately as CS181L_Week01_Name.docx.

  • Title: Arial/Calibri, 18–20 pt, bold, centered
  • Introduction heading: bold, 14–16 pt + 80–100 word paragraph (justified)
  • Bulleted list: ≥5 items under "Common Applications of ICT"
  • Numbered list: ≥4 items under "Benefits of ICT" — automatic numbering only
  • Table: ≥3 columns × 4 rows, distinct header row
  • Picture + ≥2 shapes, header, footer, page number, symbol
💡
Filename rule: never submit Document1.docx. The name must show course + week + your name, e.g. CS181L_Week01_Ali.docx.

Step-by-Step Recipe

  1. Create & save → Blank Document → save with the correct filename
  2. Title → type, format 18–20 pt bold center, add spacing below
  3. Introduction → heading + one well-aligned 80–100 word paragraph
  4. Paragraph formatting → alignment, line spacing, paragraph spacing, indentation
  5. Bulleted list → standard bullet style, consistent spacing
  6. Numbered list → Insert numbering (never type "1." manually!)
  7. Table → Insert → Table (3×4+), style the header row, adjust widths
  8. Picture → Insert → Pictures → ICT image → resize proportionally → set text wrapping
  9. Shapes → Insert → Shapes → 2+ (callout example: "ICT Makes Communication Faster")
  10. Header → "CS-181L — Application of ICT Lab"
  11. Footer → "Department of Computer Science — Air University Islamabad"
  12. Page number → Bottom of Page → Plain Number
  13. Symbol → Insert → Symbol → e.g. © ✓ ★ (placed meaningfully)
  14. Print Preview → final check → ~one page
⚠️
Common mistakes: manually typed list numbers (breaks when reordering), picture covering text (use Wrap Text), symbol pasted randomly (place it in the copyright line).

🧠 Memory Tricks — Week 01

  • Word tabs in order → "Friends Help Insert Dangerous Layouts" — File, Home, Insert, Design, Layout.
  • Font vs paragraph → Font = per character (bold, size) · Paragraph = per block (spacing, indent, alignment).

⚡ Quick Tips — Week 01

📋

Automatic lists

Always use Word's bulleted/numbered list buttons — manual numbers never renumber themselves.

🖼️

Wrap text first

Set picture wrapping (Square/Tight) before dragging it around — text flows instead of jumping.

🔤

Two fonts max

Professional ≠ decorative. One font for headings, one for body is plenty.

📐

Check with Print Preview

Ctrl+P preview catches overflow and spacing issues you can't see while editing.

Q1

Which shortcut saves the document?

↻ tap
A

Ctrl+S. Related: Ctrl+Z undo · Ctrl+P print preview · Ctrl+B/I/U formatting.

Q2

Why never type "1." manually in a list?

↻ tap
A

Manual numbers don't renumber when you reorder/delete items. Always use Insert → Numbering.

Q3

Font vs paragraph formatting?

↻ tap
A

Font = per character (bold, size, colour) · Paragraph = per block (alignment, spacing, indent).

Q4

Picture covers my text — what's wrong?

↻ tap
A

Missing text wrapping. Right-click picture → Wrap Text → Square/Tight so text flows around it.

Q5

What does Print Preview catch?

↻ tap
A

Overflow past margins, bad page breaks and spacing issues invisible in normal editing view.

Task 1 — Page Design & Layout

A4 size→ Theme→ Margins + Portrait→ Page border→ 2-column section→ Page break → Pg 2
  • Create a two-page document: "ICT in Modern Education" with title, headings, paragraphs, bulleted list
  • Apply a built-in document theme (Design tab)
  • One short section uses a two-column layout (Layout → Columns)
  • Page break (Ctrl+Enter) so section 2 starts exactly on Page 2
💡
Ctrl+Enter, not Enter! Pressing Enter repeatedly breaks the layout when anything shifts. A real page break keeps sections glued to their page.

Task 4 — Mathematical Formulas

Use Insert → Equation (or Alt + =) — never type formulas as plain text. Use Equation tools for fractions, superscripts, roots, brackets and symbols.

#FormulaWhere it's used
1Mean: x̄ = (x₁ + x₂ + … + xₙ) / nAverage marks, averages in analytics
2Percentage: (Obtained / Total) × 100Result calculation
3Quadratic: x = (−b ± √(b² − 4ac)) / 2aAlgebra foundation
4Circle area: A = πr²Basic geometry
Place cursor → Insert → Equation (or press Alt + =) Pick structure from Equation Tools → fractions / scripts / radicals Click outside the equation when finished Center each equation on its own line

🎬 Worked Example — Build the two-page lab document

🧩 From blank page → every feature the checker wants
1Page setup first (Layout tab): size A4 · margins Normal (or as asked) · orientation Portrait — set the canvas before decorating it.
2Two columns: Layout → Columns → Two. Type the body — it reflows into both columns automatically.
3Page border: Design → Page Borders → Box style → OK. (Design tab = themes + borders — that's its whole personality.)
4WordArt heading: Insert → WordArt → pick a style → type → Text Fill/Outline/Effects to customize → Wrap Text → In Front of Text so you can drag it anywhere.
5Equations (NOT typed text!): Insert → Equation (or Alt + =) → build: 
average = (a + b + c) / 3
percent  = (marks / total) × 100
x = (−b ± √(b² − 4ac)) / 2a
A = πr²
6Page break & footer: Ctrl+Enter for a clean page 2 → Insert → Page Number → bottom → save as RegID_Lab02.docx.
7Final pass: Print Preview → check borders, columns, WordArt position, equation rendering → save once more.

🧠 Memory Tricks — Week 02

  • Alt + = summons the equation editor — "Algebra + =quations". Never fake it with plain text; checkers open the file and click the object.
  • Design vs Layout → Design = look (themes, watermarks, page borders) · Layout = geometry (margins, columns, orientation, breaks).
  • WordArt positioning → invisible problems are wrap problems: set Wrap Text → In Front of Text before dragging.
  • Quadratic formula → "x equals minus b, plus or minus root, all over 2a" — sing it while inserting.
  • Line spacing → 1.15 = modern default · 1.5 = exam-friendly · Justify = tidy both edges (Ctrl+J).

⚡ Quick Tips — Week 02

⌨️

Alt + =

The equation shortcut. Once your fingers know it, inserting formulas is instant.

📄

Navigation Pane

View → Navigation Pane shows your heading tree — broken structure becomes obvious instantly.

🎨

Themes first

Apply the theme before styling individual elements — otherwise you overwrite your own work.

📐

Exactly 2 pages

Use a real page break, not a pile of Enters. Check with Print Preview before submitting.

🔤

WordArt ≠ text

WordArt objects float — use Wrap Text so they never sit on top of your paragraphs.

🧮

Real equations

Type "x^2" inside the equation editor and press space — Word auto-formats it into a proper superscript.
