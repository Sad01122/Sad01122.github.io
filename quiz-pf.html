⭐ Week 1 — Think Like a Programmer

Q1

Program vs programming language?

↻ tap
A

Program = specific instructions + data performing a task. Language = formal notation used to write them (C++, Java, Python).

Q2

Stages from source code to executable?

↻ tap
A

Source → Preprocess (#include/#define) → Compile → Link (libraries) → Executable. CPU never runs C++ text directly.

Q3

Flowchart symbols — 4 key ones?

↻ tap
A

Oval = Terminator (Start/End) · Parallelogram = I/O · Rectangle = Process · Diamond = Decision.

Q4

20 - 6 / 2 * 3 = ? with reasoning

↻ tap
A

11 — / and * beat −: 6/2=3 → 3×3=9 → 20−9=11.

Q5

Declaration vs initialization vs assignment?

↻ tap
A

Declare int a; create · Initialize int a = 3; first value at creation · Assign a = 4; replace later. Initialize before use!

Q6

Identifier rules + one invalid example?

↻ tap
A

Start with letter/underscore; letters, digits, underscore after; no spaces/hyphens; keywords reserved; case-sensitive. Invalid: 2factor, login-count, int.

⭐ Week 2 — Data & Expressions

Q1

2 + 3 * 4 and (8+4)/2 + 3*2?

↻ tap
A

14 (× before +) and 12 (parens → 6, ×→ 6, + → 12). Precedence: () > * / % > + −.

Q2

Why does int avg = 5 / 2; give 2?

↻ tap
A

Integer division discards the fraction (int ÷ int stays int). Use a double operand: 5.0 / 2 → 2.5.

Q3

static_cast<int>(9.8) → ? Round or chop?

↻ tap
A

9 — conversion truncates the decimal, it never rounds (4.9 → 4 too).

Q4

uint8_t x = 255; x = x + 1; → ?

↻ tap
A

0 — unsigned arithmetic wraps mod 2⁸ (defined). Signed overflow would be undefined behavior — demo wraps are a teaching model only.

Q5

4-digit counter: 9999+1 and 0000−1?

↻ tap
A

→ 0000 = overflow · → 9999 = underflow. Range = 0…10ⁿ−1 (odometer model).

Q6

Debugging process steps?

↻ tap
A

Observe → Trace (hand trace!) → Hypothesize → Fix → Retest. Investigation, not guessing.

⭐ Week 3 — Decision Making

Q1

= vs ==?

↻ tap
A

= assigns (stores a value) · == compares (returns bool). if (x = 5) is the classic bug.

Q2

Dangling else — what happens & fix?

↻ tap
A

An else binds to the nearest unmatched if (often not the one you meant). Fix: braces around blocks.

Q3

Correct range test for 10–90?

↻ tap
A

x >= 10 && x <= 90 — range ends always join with &&; || matches nearly everything; chained 10<=x<=90 won't compile as intended.

Q4

Why "strictest first" in else-if?

↻ tap
A

First true branch wins — test >= 90 before >= 80, or every 95 lands in the 80 bucket.

Q5

switch without break?

↻ tap
A

Fall-through — execution continues into the next case (bug unless grouping cases intentionally).

Q6

&& vs || truth at a glance?

↻ tap
A

&& true only when BOTH true · || false only when BOTH false · ! flips. Short-circuit: && stops at first F, || at first T.

📝 Test Quiz — 15 MCQs (3 per week group)

⚠️
Pick one option per question, then hit Check Answers. Explanations unlock after grading. Target: 12/15 (80%)+. Use Reset to retry — aim to beat your score without notes.

1Which statement best describes a program?Week 1

Answer: B. The program = instructions + data doing the job. The language (option A) is just the notation used to write it.

2Correct order of compilation stages?Week 1

Answer: B. #include/#define are handled first (preprocess), the result is compiled to object code, libraries are linked, and the executable is produced.

3In a flowchart, a diamond represents…Week 1

Answer: C. Oval = Terminator · Parallelogram = I/O · Rectangle = Process · Diamond = Decision.

4What is stored in int result = 20 - 6 / 2 * 3; ?Week 1

Answer: C. / and * bind tighter than -: 6/2=3 → 3×3=9 → 20−9 = 11.

5Which identifier is invalid?Week 1

Answer: C. Identifiers cannot start with a digit — user2 is fine (digit at the end), 2factor is not.

6int x = 5; x = x + 2; — final value of x?Week 2

Answer: C. = is an update: read 5 → add 2 → store 7 back into x. (It is not a mathematical equality.)

7In C++, 7 / 2 evaluates to…Week 2

Answer: A. Both operands are int → integer division discards the fraction. 7.0 / 2 would give 3.5.

8int x = static_cast<int>(9.8); stores…Week 2

Answer: B. Conversion to int chops off the decimal — never rounds (4.9 → 4 too).

917 % 5 equals…Week 2

Answer: B. % = remainder: 17 = 5×3 + 2.

10uint8_t x = 255; x = x + 1; — x becomes…Week 2

Answer: B. Unsigned arithmetic wraps modulo 2⁸ (defined behavior): 255+1 → 0. Option D applies to signed overflow instead.

11if (x = 5) { … } — what is happening?Week 3

Answer: B. = stores a value (5), and the condition then tests a non-zero value → true. Use == to compare.

12A dangling else binds to…Week 3

Answer: B. C++ matches an else with the closest if that doesn't have one yet. Fix ambiguity with braces {}.

13Correct range test for 10 ≤ x ≤ 90?Week 3

Answer: B. Range ends join with &&. Option A isn't valid chained comparison in C++; option C matches nearly every number; option D isn't C++ syntax.

14In an else-if ladder…Week 3

Answer: B. Top-down test, first true wins, else = fallback. That's why order matters — test strictest scores first (90 before 80).

15Missing break in a switch causes…Week 3

Answer: B. Execution keeps falling into subsequent cases until a break/return (or the end). Useful only when grouping cases on purpose.
