What is a Proposition?

Definition 1. A proposition is a declarative sentence (declares a fact) that is either true or false but not both.

✅ Example 1 — all propositions
1Washington, D.C., is the capital of the United States of America.T
2Toronto is the capital of Canada.F (Ottawa is)
31 + 1 = 2T
42 + 2 = 3F
❌ Example 2 — NOT propositions
1What time is it?question — not declarative
2Read this carefully.command — not declarative
3x + 1 = 2no truth value until x is assigned
4x + y = zsame — becomes a proposition with values
💡
Notation: variables p, q, r, s… stand for propositions · truth values T / F. Aristotle (>2300 yrs ago) systematized logic · George Boole, 1854, The Laws of Thought studied compound propositions (Not, Or, And).

Logic & Bit Operations

Truth ↔ bits: T = 1, F = 0.

Definition 7. A bit string is a sequence of zero or more bits; its length = number of bits. Example: 101010011 is a bit string of length nine.

Bitwise OR / AND / XOR — 0110 1011 0110 vs 1100 0001 1101
🧠
Do it bit by bit, same position with same position — the old truth tables wearing 0/1 costumes: OR = 1 if any 1 · AND = 1 if both 1 · XOR = 1 if different.

🧠 Memory Tricks

  • Proposition test → must be declarative + definitely T or F. Questions, commands, and variable-riddled sentences fail.
  • Connectives in order → Not · And · Or · If-then · Iff — say them as a word: NAOI-I.
  • → fails only at T→F — a promise breaks only when kept-and-then-betrayed; F hypothesis is automatically T.
  • Contraposite flips and negates = keeps the truth · Converse just flips · Inverse just negates. "Only the contra keeps the truth."
  • ↔ = twins → true when p and q match (TT or FF).
  • Sufficient → left (p), necessary → right (q) — "p is sufficient for q" / "q is necessary for p".
  • Range of truth for →: T,T → T · T,F → F · F,* → T (generous to false hypotheses).
  • Precedence ladder → ¬ ∧ ∨ → ↔ (Not first, Iff last).

Consistency & Boolean Web Search

  • Consistent specifications = at least one truth assignment makes all of them true (no hidden contradiction).
  • Worked example: p = "diagnostic stored in buffer", q = "retransmitted". Specs p ∨ q, ¬p, p → q → start from the unit clause ¬p ⇒ p = F → p ∨ q forces q = T → p→q is vacuously T. Consistent (p=F, q=T). Add ¬q → contradiction with q=T → inconsistent.
  • Boolean search = logic on words: NEW AND MEXICO AND UNIVERSITIES · (NEW AND MEXICO OR ARIZONA) AND UNIVERSITIES (AND binds tighter) · (MEXICO AND UNIVERSITIES) NOT NEW — Google writes NOT as -.
🧠
Consistency shortcut: attack the unit clauses first (a lone ¬p tells you p = F instantly), then propagate — no full truth table needed for 2–3 variables.

Universal Quantifier ∀ — One Counterexample Kills It

∀x P(x) over a finite domain is just a big AND
  • Read ∀x P(x) as "for all x" / "for every x" / "for each" / "given any" / "for arbitrary". An element with P false = counterexample.
  • ∀x (x + 1 > x) over ℝ → T (holds for every real).
  • ∀x (x < 2) over ℝ → F; counterexample x = 3.
  • ∀x (x² > 0) over ℤ → F; counterexample x = 0 (0² = 0, not > 0).
  • Domain matters: ∀x(x² > x) is F over ℝ (e.g. x = ½) but T over ℤ — x² > x ⇔ x(x−1) > 0 ⇔ x < 0 or x > 1, and no integer sits strictly between 0 and 1.
❓
Exam habit: hunting a counterexample? Try boundaries first — 0, 1, −1, ½. x = 0 kills x² > 0; x = ½ kills x² > x; x = 3 kills x < 2.

Definition. p and q are logically equivalent — written p ≡ q — when p ↔ q is a tautology, i.e. their final truth-table columns match on every row.

🧠

De Morgan's Laws — and Negating English

LawFormRead aloud
De Morgan 1¬(p ∧ q) ≡ ¬p ∨ ¬q"not both" = "at least one is not"
De Morgan 2¬(p ∨ q) ≡ ¬p ∧ ¬q"not either" = "neither"
n-variable form¬(p₁∨…∨pₙ) ≡ ¬p₁∧…∧¬pₙ (and the ∧↔∨ mirror)negation flips every operator and hits every atom
  • Negate: "Miguel has a cellphone and a laptop" → ¬p ∨ ¬q (he's missing at least one).
  • Negate: "Heather or Steve will go to the concert" → ¬p ∧ ¬q (neither goes).
  • Conditional disguise (proved by table): p → q ≡ ¬p ∨ q — every if-then is really an "or". From it follow the contrapositive p→q ≡ ¬q→¬p and p ∨ q ≡ ¬p → q.
  • Distributive (both directions): p ∨ (q ∧ r) ≡ (p ∨ q) ∧ (p ∨ r) · p ∧ (q ∨ r) ≡ (p ∧ q) ∨ (p ∧ r).
  • Absorption (easy to forget): p ∨ (p ∧ q) ≡ p · p ∧ (p ∨ q) ≡ p — the lone p swallows the phrase containing p.

⚠️
Classic non-equivalence: p → q is NOT q → p (that's the converse). The only equivalent flip is the contrapositive ¬q → ¬p. If you forget a Table 7 row, rebuild it in 10 seconds from p→q ≡ ¬p∨q + De Morgan.

Existential Quantifier ∃ — "One Witness Is Enough"

Definition 3. The existential quantification of P(x) is the proposition "There exists an element x in the domain such that P(x)." Notation ∃x P(x); ∃ = the existential quantifier. Read as: "there is an x such that P(x)" · "there is at least one x" · "for some x P(x)".

ExampleDomainWitness / failureTruth
∃x (x > 3)ℝx = 4 worksT
∃x (x = x + 1)ℝfalse for every xF
∃x (x² > 10){1, 2, 3, 4}P(1)∨P(2)∨P(3)∨P(4); 16 > 10 ✓T
  • Finite domain → big OR: ∃x P(x) ≡ P(x₁) ∨ P(x₂) ∨ … ∨ P(xₙ) — true iff at least one term is true. (Lecture 3–4: ∀ was the big AND.)
  • Uniqueness quantifier ∃! (or ∃¹): "there exists a unique x" / "exactly one" / "one and only one" — e.g. ∃!x (x − 1 = 0) over ℝ (the one and only witness is x = 1).
🧠
∀ vs ∃: ∀ = AND-gate (one counterexample kills it) · ∃ = OR-gate (one witness saves it).

Precedence & Quantified Equivalence

  • Quantifiers bind tighter than every propositional operator. ∀x P(x) ∨ Q(x) means (∀x P(x)) ∨ Q(x), not ∀x(P(x) ∨ Q(x)) — always parenthesize when mixing.
  • Definition 4. Statements with predicates/quantifiers are logically equivalent (≡) iff they have the same truth value no matter which predicates and which domain are used — no truth table can check "all predicates", hence the two-direction argument style.
  • Ex 14: ∀x(P(x) ∧ Q(x)) ≡ ∀x P(x) ∧ ∀x Q(x) — prove → then ←, using a generic element a of the domain (same a on both sides; predicates share the domain, so no conflict).
⚠️
∀ distributes over ∧ — but do not assume it distributes over ∨, and ∃ has its own mirror habits. Stick to the laws on the slides + quantifier De Morgan below.

NegationEquivalentWhen is the negation true?

Translating English (Domain Matters!) & Nested Quantifiers

EnglishDomain = the groupDomain = everyone

Arguments — What "Valid" Really Means

  • Argument: a sequence of statements ending in a conclusion; the rest are premises.
  • Valid argument: it is impossible for all premises to be true and the conclusion false — the conclusion must follow from the premises' truth.
  • Argument form: the same shape with variables; premises p₁…pₙ, conclusion q → valid iff (p₁ ∧ … ∧ pₙ) → q is a tautology.
  • Slide examples: password→network (modus ponens shape) · Honda-or-Saturn + no-Honda → Saturn (disjunctive syllogism shape) · toasters of gold → gold are time machines → toasters are time machines (hypothetical syllogism shape).
⚠️
Valid ≠ true conclusion. The √2 argument (√2 > 3 ⇒ (√2)² > 3²) is a valid modus ponens form but its premise is false — and the conclusion is false too. Form only says: if the premises were true, the conclusion couldn't be false.

Building Longer Arguments (Ex 6–8) & the Two Fallacies

Ex 6 chain: premises ¬p∧q, r→p, ¬r→s, s→t ∴ t

StepReason
1. ¬p ∧ qPremise
2. ¬pSimplification from (1)
3. r → pPremise
4. ¬rModus tollens from (2),(3)
5. ¬r → sPremise
6. sModus ponens from (4),(5)
7. s → tPremise

  • Ex 7: rewrite p→q as its contrapositive ¬q→¬p, then two hypothetical syllogisms give ¬q→s (email → program, ¬email → sleep, sleep → refreshed ∴ ¬program → refreshed).
  • Ex 8 resolution: "Jasmine skis ∨ it's not snowing" + "it's snowing ∨ Bart plays hockey" ⇒ "Jasmine skis ∨ Bart plays hockey" (¬p∨q, p∨r ∴ q∨r).
  • Fallacy 1 — affirming the conclusion: p→q, q ∴ p. Invalid: you can learn discrete math without doing every problem.
  • Fallacy 2 — denying the hypothesis: p→q, ¬p ∴ ¬q. Invalid: skipping the problems doesn't prevent learning.
🧠
Names across books: affirming the conclusion = converse error · denying the hypothesis = inverse error. The safe flip is always the contrapositive (¬q → ¬p).
